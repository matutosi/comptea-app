# 植生学・植物社会学の基礎メモ(comptea 用)

comptea が扱うデータの背景知識をまとめる．
毎回調べ直さずに済むよう，**組成表の構造**と**表に現れる記号**を中心に整理した．
出典は末尾．

## 1. 何をしている分野か

- **植生学 / 植物社会学(phytosociology)**: 植物の集まり(群落)を，
  そこに出現する種の組み合わせ(種組成)によって分類・記載する分野．
- 主流は **Braun-Blanquet 法**(ブラウン・ブランケ法，チューリッヒ・モンペリエ学派)．
  日本の植生調査・環境アセスメントの標準的な方法として広く使われている．
- 手順の骨格
  1. 現地に**方形区(コドラート)**を置き，出現種と量を記録する → **植生調査票**
  2. 多数の調査票を1枚の表にまとめ，行(種)と列(地点)を**並べ替える**(表操作) → **組成表**
  3. 似た出現の仕方をする地点のまとまりを**群落・群集**として区分する

## 2. 組成表(compositional table)の構造

comptea の入力そのもの．典型的なレイアウトは次のとおり．

```
                    ┌──── 表頭(地点の情報) ────────────┐
                    │ 群落名 A      │ 群落名 B         │
                    │ 地点 1  2  3  │ 4  5  6          │
                    │ 標高  / 傾斜 / 方位 / 面積 / ...  │
    ┌───────┬───────┼──────────────────────────────────┤
    │ 階層  │ 種名  │                                  │
表側│ T1    │ 種 a  │ 5  4  3  │  ・  ・  ・            │
    │ T1    │ 種 b  │ 2  +  1  │  ・  ・  ・            │
    │ K     │ 種 c  │ ・ ・ ・  │  3  2  +              │
    └───────┴───────┴──────────────────────────────────┘
```

- **列(縦) = 1つの地点(調査区，スタンド)**
- **行(横) = 1つの種**(＋その種が出現した階層)
- セル = その地点でその種がどれだけ出現したか(**被度**，下記)
- **表側**: 種名(**和名**(カタカナ) and/or **学名**(ラテン語，斜体))と**階層**
- **表頭**: 地点名・地点番号，調査日，標高，傾斜，方位，方形区面積，
  各階層の高さ・植被率，出現種数など
- **表頭に群落名**が入ることがある．群落名 = 同じような出現の仕方をする地点の集合の名前
- **本体の途中に「見出し行」が入る**．種を「標徴種」「区分種」「随伴種」などに
  グループ分けし，その名前を書いた行(`Kennart d. Ass. : 群集標徴種` など)．
  被度の欄は空になる．
  - これは**データそのものではなく，データを解析した結果の解釈**を示すもの．
    どの種がその群落を特徴づけるか，という著者の判断が入る．
  - デジタル化では**取りこぼしても実害は小さい**(被度の情報が無いため)．
    いっぽう本文の行が落ちると，種が1つ丸ごと消えるので実害が大きい．
    表のいちばん上の行も，種名ではなくこの見出しであることが多い．
- **表の下の「1回出現種」の列挙**: 1地点にしか出現しなかった種は，
  表を小さくするために本体から外し，表の下に
  「地点名 ＋ 種名(＋被度)」の形で**文章として列挙**することが多い．
  組成表を読むうえでは本体と同じ情報なので，デジタル化するときも取り込む必要がある．
- 表の右端に**常在度**(その群落の何割の地点にその種が出るか．V/IV/III/II/I の5段階)が
  付くことがある(常在度表)
- **1つの表に，群落の要約列と単独地点の列が混ざることがある**
  (2026-09-05 に日本植生誌-近畿の折り込みで確認)．どちらも `頭(括弧の中)` の形に
  組まれるので，**形だけでは区別できない**．
  - 群落の要約列: `IV(+-3)` = 常在度IV，被度の**範囲** `+`〜`3`
  - 単独地点の列: `2(3-4)` = 被度2，群度の**範囲** `3`〜`4`
  頭がローマ数字か算用数字かで分かれ，**列ごとにどちらかに揃う**
  (s01115_22_p2 は 25 列のうち 9 列が算用数字，11_p1 は 14 列が 7 列ずつ)．
  ローマ数字の `I` と算用数字の `1` は字形が違う(`I` は上下に serif，`1` は旗付き)が，
  OCR は取り違えるので，**列ごとの多数決で決める**のが確か．

## 3. 表に現れる記号

### 3.1 被度階級(優占度階級)

セルに入る値．方形区に占めるその種の被覆面積の割合を階級化したもの．

| 記号 | 被度 |
|:----:|:-----|
| 5 | 75-100% |
| 4 | 50-75% |
| 3 | 25-50% |
| 2 | 10-25% |
| 1 | 1-10%(個体数は多い) |
| + | 1%未満(個体数は少ない) |
| r | ごくまれ．1-数個体(使わない流儀もある) |

- 「5,4,3,2,1,+ の**6段階**」とするのが日本の実務では一般的．
  `r` を足して7段階とする文献もある．
- 空欄・`・`・`.` は「出現しない」を意味する．

### 3.2 群度

「どういう散らばり方で生えているか」の5段階．

| 記号 | 意味 |
|:----:|:-----|
| 5 | 大きなマット状で全域を覆う |
| 4 | パッチ状，または切れ切れのマット状 |
| 3 | 大きな群をつくる |
| 2 | 小さな群をつくる |
| 1 | 単独で生える |

### 3.3 セルの表記ルール(comptea が扱うデータの実際)

**「被度・群度」の順**で併記する．`4・2` `4.2` `3-2` のように書く．

| セルの表記 | 意味 |
|:---|:---|
| `4・2` | 被度 4，群度 2 |
| `+・2` | 被度 +，群度 2 |
| `+` | **`+・1` の省略形**(被度 +，群度 1) |
| `r` | **`r・1` の省略形**(被度 r，群度 1)．たまに出る |
| `・` のみ | **出現しなかった**(欠測ではない) |

- **省略するのは群度が1のときだけ**．`+` は `+・1` を意味する．
  被度が `+` や `r` でも**群度2以上なら明示される**(`+・2` `r・2`)．
  - 実データでは **`+・2` が最頻値**だった(`ocred2.csv` の組成部46件中10件)．
  - 以前このファイルに「`+` や `r` に群度が併記されることはない」と書いていたが，
    **誤り**だった．その記述にもとづく検証で，正しい `+・2` を
    10件すべて `Need Check` にしていた(2026-08-08 修正)．
- `・` は「区切り記号」としても「非出現」としても現れる．
  1文字だけの `・` は非出現，数字に挟まれた `・` は区切り，と読み分ける必要がある．

**実装との対応**: `correct_comp()` が `;` 区切りに正規化し，
その場で `validate_comp()` が `(?:[54321]|[+r])(?:;[54321])?` の全体一致で検証して
`status` を返す．被度は 5 4 3 2 1 + r のいずれかで，群度 1-5 を続けられる．
`・` だけのセルは空文字になり，非出現として `status` は付けない．

### 3.4 階層

森林はふつう5層に区分する．**表側の「階層」列**に記号で入る．

| 記号 | 層 | 目安の高さ |
|:----:|:---|:---|
| T1 | 高木層 | 林冠に達する |
| T2 | 亜高木層 | その下 |
| S | 低木層 | 数 m 以下 |
| K(または H) | 草本層 | 約 50 cm 以下 |
| M(または B) | コケ層 | 地表すれすれ |

- `K` はドイツ語 *Krautschicht*(草本層)由来．`H`(herb)を使う流儀もある．
- `B` は *Baumschicht*(高木層)由来だが，日本では `T`(tree)が主流．
- 細分するときは `S1` `S2` `K1` `K2` のように添字を付ける．
- comptea の `validate_layer()` は `[BTSKH][12]?` の全体一致で見ており，上記の流儀を両方カバーしている．
  `correct_layer()` がこれを呼んで `status` を返す．
- 同じ種が複数の階層に出ることがあるため，**種名が同じ行が複数現れうる**
  (種名だけでは行を一意に決められない)．
  1つのセルに `S;K` のようにまとめて書かれることもある．
  comptea はこれを**文字列のまま**保持し(被度をどちらの階層に割り当てるか決められないため)，
  `status` を `multi` にして目視を促す．

## 4. 用語ミニ辞典

| 用語 | 意味 |
|:---|:---|
| 方形区・コドラート(quadrat) | 調査のために区切った一定面積の区画 |
| スタンド・調査区 | 1回の調査の単位．組成表の1列 |
| 相観(physiognomy) | 群落の見かけ．優占種と生活形で決まる |
| 群落(community) | 植物の集まり一般．ゆるい呼び方 |
| 群集(association) | 植物社会学の基本単位．標徴種で定義される．学名は `-etum` で終わる |
| 群団 / オーダー / クラス | 群集の上位単位．それぞれ `-ion` / `-etalia` / `-etea` で終わる |
| 標徴種(character species) | その群集に特徴的に出る種．群集を定義する |
| 識別種(differential species) | 隣り合う単位と区別するのに使う種 |
| 常在度(constancy) | 群落内でその種が出現する地点の割合．V(81-100%)-I(1-20%) |
| 植被率 | 階層ごとの，地表を覆う割合(%) |
| 潜在自然植生 | 人為を取り去ったときに成立するはずの植生 |

## 5. comptea の観点でのポイント

- **文字種が場所によって違う**のが OCR を難しくしている中心的な理由
  - 学名: ラテン文字(斜体，`var.` `subsp.` などの略号を含む)
  - 和名: カタカナ(まれに漢字)
  - 階層: 半角英数字の短い記号(`T1` `S` `K`)
  - 被度・群度: 数字と記号(`5` `4・2` `+` `r` `・`)
  - 地点情報: 数字と単位
- **紛れやすい文字**が多い
  - `+` ↔ `十`(漢数字)，`t`，`4`
  - `1` ↔ `l` `I` `|`，`5` ↔ `S`，`0` ↔ `O`
  - `・`(区切り・非出現) ↔ `.` ↔ ノイズ
  - `correct_layer()` が `5`→`S` を，`correct_comp()` が `十`→`+` を直しているのはこのため
- **古い資料が多い**(1980年代など)．スキャン解像度が低く，罫線がかすれる，傾く
- **セルが空**であることが多い(疎な表)．空セルを「読めなかった」と混同しない
- 種名は**既知のリストと突き合わせられる**(`s_name.txt` / `j_name.txt` ＋ 編集距離)．
  被度・階層は**取りうる値が有限**なので，正規表現で検証できる．
  この2つが OCR 誤りを大きく減らす鍵になっている．
