# 画像を読むときの約束

`apply_text.py` に渡す TSV の書き方．
**読んだままを書く**のが原則で，直すのは Python の補正に任せる
(同じ入力に同じ出力が返るようにするため)．

## TSV の形

タブ区切り．1行目は見出し．`cell_id` は切り出した画像に焼いてある番号．

```
cell_id	text
35	+;2
41	オオツルウメモドキ
88	Tab. 85. コウヤマキ植林 調査番号：SO-216 調査面積：100m² ...
```

- **読めないものは書かない**．行を落とせば，そのセルは `Need Check` のまま残る
- タブと改行は使えない．文章の領域は改行を**半角空白**にしてつなぐ

## 被度(`comp` のセル)

「被度・群度」の順．**区切りは `;`** と書く(`・` でも補正が受けるが `;` が確実)．

| 画像 | 書く |
|:---|:---|
| `4・4` | `4;4` |
| `+・2` | `+;2` |
| `+` | `+` (群度1は省略されている．補うのは Python の仕事) |
| `r` | `r` |
| `・` だけ | `` (空．非出現なので行を書かない) |
| `1・1` | `1;1` |

取りうる被度は `5 4 3 2 1 + r`，群度は `5 4 3 2 1`．
**それ以外に読めたら，読み違えを疑う**(`l` は `1`，`I` は `1`，`十` は `+`)．
どうしても決められないときは書かない．

## 階層(`layer` のセル)

`T1 T2 S K M` など．資料により `B1 B2` を使う．
**1つのセルに複数あるときは `;` でつなぐ**(`S・K` → `S;K`)．
行は分けない(被度をどちらの階層に割り当てるか決められないため)．

## 種名(`species_col` = 和名 / `sname` = 学名)

- **読んだままを書く**．辞書との照合は `correct_name()` が行う
- 学名は `属名 種小名` の形．`var.` `subsp.` はそのまま
- 和名はカタカナ．行またぎで割れていたらつなぐ(`ク` + `ロマツ` → `クロマツ`)
- **知っている種名に「直して」書かない**．辞書に無い種はそのまま残す必要がある

## 文章形式の表頭(`header` の領域)

読み順(上から，行の中は左から)につないで1つの文字列にする．

```
Tab. 85. コウヤマキ植林 調査番号：SO-216 調査年月日：1983年5月21日 海抜高度：640m 方位及び傾斜：S 2° 調査面積：100m² 高木層の高さ：14m 高木層の植被率：70% ...
```

- 表題(`Tab. 85. …`)が頭に付いていてよい．構文解析が無視する
- 項目名が行をまたいで割れていたらつなぐ(`高木層の` + `植被率`)
- `方位及び傾斜：S 2°` のように2項目で値を共有する形は**そのまま**書く
  (`parse_text` がほどく)
- 単位(`m` `m²` `%` `°`)は落とさずに書く．範囲の検査に使う

## 1回出現種(`once_species` の領域)

同じく読み順につなぐ．

```
出現1回の種 Außerdem je einmal in Lfd.Nr. 1 : Osmunda japonica ゼンマイ K—+, Weigela hortensis タニウツギ S—1・2, in 3 : ...
```

- 地点の変わり目は `in N :`．**ここを読み違えると全部ずれる**ので丁寧に見る
- 種の区切りはカンマ．各項目は「学名 和名 (階層—)被度」
- 同じ種に階層が2つ続くことがある(`ヒメドコロ S—+, K—+`)．そのまま書く
- **末尾に注意**．列挙のあとに `Lage d. Aufn. 調査地：…` が続くことがある．
  そこからは書かない(`kinki_017` は最終行の末尾に混じる)

## 表頭の値(`header_value` のセル)

数字・方位・日付．読んだままを書く．

- `SO-194` は `SO 194` と分かれていてもよい(`correct_field_no` がつなぐ)
- 日付は数字3つでよい(`83 5 21` → `1983-05-21` に直る)
- **小数点が見えないときは書き足さない**．`0 6` は `0.6` か `6` か決められない．
  読めたままを書けば `Need Check` になり，目視に回る
