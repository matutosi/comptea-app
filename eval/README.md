# 物差し (eval)

手を入れる前と後を，同じ尺度で比べるための道具です．

| ファイル | 測るもの |
|:---|:---|
| `eval_grid.py` | 格子を正解ラベルと突き合わせる (recall / precision / ずれ / 太さ) |
| `eval_read.py` | 読み取りを正解表と突き合わせる (クラスごとの一致率) |
| `scan_blocks.py` | 段が丸ごと落ちていないかだけを見る (ラベルが要らない) |
| `label_gaps.py` | 余分な帯を切り出して並べ，付け漏れなら書き足す |
| `make_labels.py` | できあがった格子を labelme / YOLO のラベルに戻す |
| `build_dataset.py` | 既存の train / val の分け方を保ったまま，新しい断片を足す |
| `compare_runs.py` | **2 つの通しを表ごとに比べる** (要確認・変わったセル・境のインク) |

**上の 6 本は，このリポジトリだけでは動きません**．
ラベルを付けたスキャン (`labelme_data/`) と，人が書き起こした正解表 (`truth/`) が
要りますが，どちらも著作権のため公開していません．

## データの置き場を指す

既定値は `labelme_data/…`・`truth/…` のような**相対の場所**なので，
データを置いたディレクトリで動かします．
**環境変数 `COMPTEA_DATA` を設定しておけば，どこから呼んでも同じように動きます**
(設定が無ければ，これまでどおり「いまいる場所」を使います)．

```bash
export COMPTEA_DATA=<データを置いた場所>     # bash
set COMPTEA_DATA=<データを置いた場所>        # Windows

python eval/eval_grid.py --split val
```

指した場所に `labelme_data/` も `truth/` も無ければ，**その場で止まります**．
既定値が相対の場所なので，黙って別の場所で動くと「0 件」で終わり，
**気づけない**ためです．

**実際の場所はここに書きません**．人によって違い，公開する情報でもありません．

読むだけでも，何をどう測ってきたかは分かります．
判断の経緯は [../docs/lessons.md](../docs/lessons.md) (原則と採否の表) と
[../docs/lessons_history.md](../docs/lessons_history.md) (日付順の詳細) にまとめてあります．

**重みの採否は，必ず通しで決めてください**．`eval_grid.py` はラベル済みの
33 枚の生の格子しか見ておらず，`rows_from_body` や `fix_columns` を通らないので，
そこを変えたときの物差しにはなりません (2026-09-06 に，格子の物差しでは
上回るのに通しでは 9% 落ちる重みがあった)．

## 2 つの通しを比べる (`compare_runs.py`)

直しの前と後で通した結果 (表ごとの作業ディレクトリを並べた置き場) を比べます．
**ラベルも正解表も要りません**．

```bash
python eval/compare_runs.py <前の置き場> <後の置き場> [表の名前 ...] [--ink] [--cells N]
```

- **先に版と設定の違いを出します** (`run_info.json`)．違えば，差が直しによるものか
  疑ってください (2026-09-16 に，前の通しがコミットしていない状態で回されて
  いたのに気づかず，後退と取り違えました)
- **変わったセルの数と，それが地点 1 に閉じているか**を出します．
  直しが狙いの場所に効いたかが分かります
- `--ink` は**箱の境にインクが乗るセル**を上半分・下半分に分けて数えます．
  **実際に読んだ箱** (`ocred.csv`) で数えるので，読む箱だけを動かす直しにも使えます．
  上下に分けると，一様でない歪みが見えます
- `--cells N` で，変わったセルを表ごとに N 個並べます．**必ず中身を見てください**

**要確認の数だけで採否を決めてはいけません**．2026-09-16 だけで 4 回，
要確認は減ったのに中身が壊れていました (本物の値が消えた・罫線を `1` と読んだ・
隣の列へ値が移った)．物差しの中身は `comptea/compare.py` にあり，的で固めています
(行番号の無い行を毎回別物と数えた誤りを含む)．
