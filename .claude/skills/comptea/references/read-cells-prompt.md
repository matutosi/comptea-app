セッション(Claude Code)がこれを読んで従います．
**誰が読んでも同じ文面を使います**(2 か所に別々の文面を置くと必ずずれるため)．

## 指示

組成表(植物社会学の植生調査表)をスキャンした画像から切り出したセルを読みます．

画像には複数のセルが並び，各セルの左上に `#<cell_id> <クラス> r<行>c<列>` が
**青字で焼き込んで**あります．この青字は目印であって，読む対象ではありません．
枠の中に写っている**印字だけ**を読みます．

このシートのクラスは **`<クラス>`** です．来る字は下の表のとおりです．

### クラスごとに来る字

| クラス | 中身 | 来る字 |
|:---|:---|:---|
| `comp` | 組成部(被度・群度) | `5 4 3 2 1 + r` と区切りの `・`．非出現は `・` か点だけ．常在度表では `I II III IV V` と括弧 |
| `layer` | 階層 | `B T S K H M` と数字(`B1` `B2` `T1` `T2`)．複数なら `;` でつなぐ |
| `species_col` | 和名 | カタカナ．まれに漢字 |
| `sname` | 学名 | ラテン文字(斜体)．`var.` `subsp.` `f.` `sp.` が入る |
| `header_value` | 表頭の値 | 数字と単位，方位(`N` `S` `E` `W`)，日付 |
| `header_item` / `header_item_ja` | 表頭の項目名 | 独文と和文の項目名 |
| `plot_row` | 地点の番号 | 数字 |

### 書き方

タブ区切りの2列で返します．1行目は見出し `cell_id` と `text`．
**それ以外は何も書きません**(説明・前置き・囲みの記号は付けない)．

```
cell_id	text
53	5;4
79	4;4
108	5;5
```

- **被度は「被度・群度」の順で，区切りは `;`**．`5・4` は `5;4`，`+・2` は `+;2`
- 群度が省略されていれば被度だけ書く(`+` は `+`)．**補うのは Python の仕事**
- **階層が複数のセルは `;` でつなぐ**(`S;K`)．行を分けない
- 文章の領域は，改行を**半角空白**にしてつなぐ

### してはいけないこと

- **読めないセルは行を書かない**．書かなければ `Need Check` のまま残り，
  人が見に行けます．**無理に埋めない**
- **推測で補わない**．`0 6` が `0.6` か `6` か決められないなら書かない
- **種名を記憶で直さない**．印字のまま書きます．
  辞書との突き合わせは Python(`correct_text.correct_name()`)がやります．
  **同じ入力に同じ出力が返る必要がある**ため
- **組成部で `・` や点だけのセルも，行を書かない**．非出現の印なので，
  空のまま置けば Python が `absent` として扱います
- **焼き込まれていない `cell_id` を書かない**．画像に無い番号は返しません
- **`review.tsv` の `suggest` 列を見ない**．あれは編集距離が出した候補で，
  **誤ることがあります**(`クツル` に `ハクツル` が出た実例)．
  画像だけを見て決めます
