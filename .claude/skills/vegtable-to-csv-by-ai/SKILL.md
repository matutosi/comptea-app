# 組成表の画像を AI が読んで CSV にする

## このスキルの立ち位置

**読むのは AI，決まった変換と検算は Python**．

- 画像を読む・表の範囲を決める・行と値を対応させる・文章を読み解くのは，AI が画像を見て行う．
- 画像の切り出し (拡大・目盛り付け)・値の分解 (`+・2` → 被度 `+`・群度 `2`)・
  縦持ちへの展開・検算は，同梱のスクリプトが毎回同じ規則で行う．
- comptea-app のコードは使わない．知見 (組成表の構造・読み違いの型) だけを使う．
- OCR は必須ではない．入っていれば補助に使ってよい ([reading-pitfalls.md](references/reading-pitfalls.md) の 6)．

必要なもの: Python 3 と `Pillow`，PDF を読むなら `pymupdf` (`pip install pillow pymupdf`)．
スクリプトの置き場は，このファイルのあるディレクトリの `scripts/`．
以下では `<skill>` と書く．

## 守ること (comptea-app で決めた方針)

1. **欠落を避けるのが最優先**．学名・和名・組成の値を落とすと後で取り戻せない．
   位置のずれは値があれば直せる．迷ったら多めに取り，読んで違うものを落とす．
2. **重要なのは 3 つ: 組成の値・和文 (和名・和文の項目名)・表頭の値**．
   独文 (学名以外のドイツ語の項目名や見出し) は多少欠けても構わない．
3. **推測で埋めない**．読めない値は `?`，自信の無い値は `+・2?` と書き，`status=check` で残す．
   `0 5` が `0.5` か `5` か決められないときに書き足さない．
4. **印字のまま書く**．学名・和名を知っている名前に「直さない」(旧名・誤植も印字どおり)．
5. **1 回出現の種と注記 (調査地・調査日) を落とさない**．本体と同じ重さのデータ．
6. **表ごとに順に片づける**．何表もまとめて読むと，どの値がどの表か分からなくなる．

## 流れ

```
1. 準備        scripts/pages.py  → ページ画像と見渡し画像
2. 見渡す      見渡し画像を読み，紙面の型を reading_log.md に書く
3. 切り分ける  scripts/crop.py --raw  (折り込み・1 ページ 2 表・横倒し)
4. 表頭を読む  → transcripts/<表>/meta.tsv・header.tsv   (地点の数を確定)
5. 本体を読む  scripts/crop.py で帯に切る → body.tsv
6. 文章を読む  1 回出現の種 → once.tsv，注記 → notes.tsv (続きのページも)
7. 変換と検算  scripts/to_csv.py → scripts/check.py → 画像に戻って直す
8. 報告
```

### 1. 準備

出力先を決める (既定は `<入力のあるディレクトリ>/vegtable_csv/`)．入力をページ画像にそろえる．

```bash
python <skill>/scripts/pages.py <入力 (PDF・PNG・JPG．複数可)> --out <出力>/work
```

`<名前>.png` (原寸) と `<名前>_overview.png` (縮小．余白に**原寸の px** の目盛り) ができる．
PDF の 1 ページが 1 枚のスキャン画像なら，画像を原寸のまま取り出す．

### 2. 見渡す

各ページの `_overview.png` を Read し，`<出力>/reading_log.md` に次を書く．

- ページごとに，**組成表がいくつあるか**・それぞれの範囲 (原寸の px)・表の番号 (`Tab. N`)
- 各表の型 ([table-structure.md の 5](references/table-structure.md#5-紙面の型))．
  1 段か **2 段組**か，**横倒し**か，表頭が**表の形か文章の形**か，階層の列があるか，常在度表か
- 表の下に **1 回出現の種**・**注記**があるか．本文・写真・図の範囲 (読まない所)
- **続きのページ**: 1 回出現の種や注記が途中で切れていないか (文の途中で終わる，
  `in N:` が最後の地点まで無い，`Lage d. Aufn.` が無い)．続きは
  - ファイル名の枝番 (`xxx-1` が表，`xxx-2` が続き．**枝番が読む順**) か，ユーザの指示で決める．
    ノンブルの順ではない (見開きでは右ページ → 左ページへ流れることがある)．
  - 入力の中に続きが見つからなければ，**ユーザに続きのページを尋ねる**
    (尋ねられない状況なら，切れていることを報告に書く)．
  - 続きのページには本文・写真と一緒に，ページ上端に流し込みが載る．
- 折り込みは隅の札 (`Tab. 12, 13, 14.`) の表の数と，見つけた表の数を合わせる．

### 3. 切り分ける (折り込み・1 ページに 2 表・横倒し)

表ごとに 1 枚の画像にする．**表の下の 1 回出現の種と注記まで含め，多めに**取る
(表の下端は形では決まらない)．横倒しなら起こす (`--rotate` は反時計回りの角度．
種名が下から上に並ぶ横倒しは `270`)．

```bash
python <skill>/scripts/crop.py <出力>/work/<ページ>.png --box X0 Y0 X1 Y1 --raw --rotate 270 --name Tab12 --out <出力>/work
python <skill>/scripts/crop.py <出力>/work/Tab12.png --max 1800 --out <出力>/work     # 起こした表の見渡し
```

切ったら，**起こした表の見渡しで 4 辺に字が掛かっていないか**を見る．
表題・通し番号の行 (横倒しの表では紙面の端) や，1 回出現の段落の行末が切れやすい．
折り込みでは，隣の表との間の余白の中ほどか紙面の端まで取る．
`scripts/crop.py --raw` は実際に切った範囲を `<名前>.box.txt` に残す．

切ったあとの 1 枚を「ページ」とみなして以下を進める．以後の座標は，その 1 枚の座標．
本のページで表が 1 つなら，切らずに進めてよい．

**見渡しから目で読んだ座標はずれる** (縮小率 0.5 の見渡しで 50〜100 px)．`scripts/crop.py` は
`--box` を既定で上下左右に 80 px 広げて切る (`--pad`)．それでも端が切れていたら，広げて切り直す．

### 4. 表頭を読む

表題と表頭を拡大して読む．**地点の数と通し番号をここで確定する** (以後の列の数の基準)．

```bash
python <skill>/scripts/crop.py <表>.png --box <表題から表頭の最終行まで> --out <出力>/work/crops
```

- 表頭の項目名の列 (独文の左端から) と値の列 (右端の地点まで) が同じ画像に入るように切る．幅が広すぎるときは
  `--tiles 1x2` などで横に分け，**y の目盛り**で行を合わせる．
- 書き方は [transcript-format.md](references/transcript-format.md) の meta.tsv・header.tsv．
- 読み終えたら，通し番号の個数と，各行の値の個数が合うかを数える．

### 5. 本体を読む

本体を**行の帯**に切り，**種名と値が同じ画像に入る**ようにして上から順に読む．

```bash
python <skill>/scripts/crop.py <表>.png --box <本体の範囲> --tiles 4x1 --out <出力>/work/crops
```

- `--box` の左端は**学名の左端より左**，右端は最後の地点 (常在度の列があればそれも) より右に取る．
- **幅が広く，種名と値を 1 枚に入れると縮小率が 0.6 を切る表** (折り込みの多くの表) は，
  左 (学名・和名・階層) と右 (**階層**・値) の 2 枚に分け，**両方に階層の列を入れる**．
  右の画像の行は，階層の記号の並び (`B1 B2 K S K …`) と `--grid` の目盛りの線で左の行に合わせる．
  目盛りの y だけでは 1 行ほどずれることがある．
- `scripts/crop.py` が表示する**縮小率が 0.6 以上**になるまで細かく切る (`・` と `+`，`1` と `I` を見分けるため)．
  帯は 20〜40 行が目安．地点が多く横に収まらないときは `--tiles 4x2` のように横にも分け，
  y の目盛りで左右のタイルの行を合わせる．隣のタイルとは 120 px (`--overlap` の 2 倍) 重なる．
  重なりの行を二重に書かない (帯の境の行は y の目盛りで確かめる)．
- 帯を 1 つ読むごとに body.tsv に書き足し，**各行の印字の数が地点の数と合うか**を確かめる
  (非出現の `・` も 1 つ)．合わなければ拡大し直す．地点が 1 つの表では，代わりに
  **種名と値の行の高さ**がそろっているか (学名だけの行と，和名と値の行を取り違えていないか) を見る．
- 見出しの行 (群集標徴種など) は `kind=group`．階層ごとの続きの行は種名を空にする．
- 2 段組は左の段を読み切ってから右の段を読む．
- 読み違いの型は [reading-pitfalls.md](references/reading-pitfalls.md)．とくに**位置のずれ**に気を付ける．

### 6. 文章を読む (1 回出現の種・注記)

表の下の段落を原寸に近い大きさで切り，読む．続きのページがあれば，**その先頭の流し込みも続けて**読む
(ページで割れた種名はつなぐ)．

- 1 回出現の種 → `once.tsv` (地点 × 種 × 階層を 1 行)．`in N:` の変わり目を丁寧に見る．
  地点が 1 つの表には 1 回出現の段落が無い (全種が本体にある)．
- 注記 (調査地・調査年月日・出典) → `notes.tsv` (地点ごとに展開)．
- 本文・図の説明は読まない．`出現1回の種` `Außerdem` `Lage d. Aufn.` `Nachweis` などで見分ける．

### 7. 変換と検算

```bash
python <skill>/scripts/to_csv.py <出力>
python <skill>/scripts/check.py <出力>
```

`scripts/check.py` の指摘は**すべて画像に戻って確かめる**．いちばん効くのは
**「出現種数と読んだ種の数」の不一致**で，ずれた地点の列を上から読み直すと，
読み落とし・行のずれ・1 回出現の種の地点の取り違えが見つかる．
不一致には別の数え方 (種 × 階層，本体だけ，見出し × 種 × 和名) の数も並ぶ．
そちらと合うなら数え方の違いで，読みは正しい (reading_log.md にそう書く)．
どれとも合わなければ `scripts/check.py <出力> --list Tab12:5` でその地点の種の一覧を出し，
画像の列を上から 1 つずつ突き合わせる．
- `status=multi` は値は確かだが階層が決まらない行．check とは別に数える．

- 直したら転記表 (transcripts) を直して，7 をやり直す．CSV を手で直さない．
- 読み直しても合わないものは，印字の出現種数が誤っていることもある．
  そのときは `reading_log.md` に「読み直して合わない」と理由を書いて残す．
- 問題が 0 件でも，正しい形の読み違い (`+` と `1`) は残りうる．
  最後に，値の密な帯を 1 つ選び，画像と body.tsv を突き合わせる．

### 8. 報告

ユーザに次を伝える．

- 出力の置き場 (`sites.csv`・`composition.csv`・`reading_log.md`)
- 表の数・地点の数・種 × 地点の行数 (本体と 1 回出現の別)
- 出現種数の照合の結果 (一致・不一致の地点数)
- `status=check`・`multi` の件数と，主な理由
- 読めなかったもの・対象外にしたもの (続きのページが無い，歪んで読めない表 など)
