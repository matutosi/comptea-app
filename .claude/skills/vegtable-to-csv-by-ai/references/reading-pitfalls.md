# 読み違いの型と対策

comptea-app で OCR と目視を重ねて確かめた誤りの型
([lessons.md の「資料と OCR の性質」](../../../../docs/lessons.md#資料と-ocr-の性質))．
AI が画像を読むときにも同じ所で間違える．

## 1. 位置 (どの行・どの列の値か)

いちばん多く，いちばん害が大きい．字は読めても**別の地点・別の種に付く**．

- **値は `・` を軸に組まれている**．`+・2` の `・` は区切り，単独の `・` は非出現．
  非出現にも印字があるので，**どの行も地点の数だけ印字が並ぶ**．
  1 行の値を読んだら，**印字の個数が地点の数と合うか**を数える
  (`・` も 1 つと数える)．合わなければ読み直す．
- 行を追うときは，**種名と値を同じ画像に入れる**．入らない幅の表は，
  `scripts/crop.py` の目盛り (原寸の y) で行を対応させる．
  目で「だいたい同じ高さ」と見るとずれる．
- 同じ種の階層ごとの行 (種名の欄が空) は，値だけの行に見える．階層の列を見て数える．
- 種名が 2 行にわたる (`Carex sachalinensis var` / `alterniflora`，和名が次の行) と，
  値は**和名の行**の高さにある．2 段組の表で起こりやすい．
- 地点の多い表は列を取り違えやすい．**罫線・群落区分の枠・通し番号**を目印に，
  10 列ごとなど区切って数える．

## 2. 字の取り違え

| 印字 | 見誤り | 見分け方 |
|:---|:---|:---|
| `+` | `十` `t` `4` `1` | 被度に `十` `t` は無い．`+` は縦横が同じ長さ |
| `1` | `l` `I` `\|` `7` | 被度・群度に `l` `I` は無い．縦罫線を `1` と読みやすい |
| `・` | `.` `,` ノイズ・`1` | 区切りか非出現か．罫線の切れ端を `1` と読まない |
| `5` | `S` `3` `6` | 階層の欄なら `S`，値の欄なら `5` |
| `2` | `z` `Z` `a` | |
| `3` | `8` `5` | 小さく薄い印字で起こる |
| `II` `III` | `I` `II` | **正しい形のまま誤る**．画数を拡大して数える |
| `(` | `6` `し` | 括弧付きの値 `(+)` |
| `0.5` | `0 5` `05` `5` | 小数点が見えなければ**書き足さない** (`check`) |

- 被度・群度・常在度・階層は**来る字が決まっている**．それ以外に見えたら拡大し直す．
  ただし決まった字に**寄せて書かない** (読めなければ `check`)．
- `II` を `I` と読むと `I(+)` という正しい形になり，形では見つからない．
  常在度表では，列の中で頭の画数が揃っているかを見る．

## 3. 名前

- **学名・和名は印字のまま**．知っている名前に「直して」書かない．
  旧名・誤植 (`Ischaenum`) も印字どおり．気づいたら `note` に書く．
- 和名はカタカナ．`属の1種` `sp.` `科の一種` など種まで決まっていない記載もある (そのまま)．
- 蘚苔類 (コケ層 `M`) は一般の和名の一覧に無いことが多い．無いことを理由に捨てない．
- 長い学名は途中で折り返す (`Euonymus alatus var. apterus f. ciliatodentatus` + 和名が次行)．
- 小さな活字の半濁点・濁点 (`ブ`/`プ`，`ヅ`/`ツ`) は拡大して見る．

## 4. 領域の取り違え

- **表の下端は形で決めない**．最後の種の行と 1 回出現の種の文章は近い．
  多めに切り出して**読んで**見分ける．
- 1 回出現の種の列挙のあと，同じ段落の続きに `Lage d. Aufn.` の注記が来る．
  そこから先を種として読まない．
- 見出しの行 (群集標徴種など) は値が空．種の行と取り違えない．
- 表頭の最終行 (出現種数) と本体の最初の行を取り違えない．表頭と本体の間の横罫線を見る．

## 5. 大きな画像

- 読み手 (AI も OCR も) は**大きな画像を縮めてから読む**．A0 の折り込みを 1 枚で渡すと
  字が潰れる．表ごとに切り，さらに行の帯・列の帯に切る
  (`scripts/crop.py` が縮小率を表示する．0.6 未満なら細かく切る)．
- 折り込みは最大 1 度ほど傾く．長い行を横にたどると，端で 1 行ずれる．
  横に分けたタイルは y の目盛りで合わせる．

## 6. OCR を補助に使うとき

- 印字が細かく AI の読みが揺れるときだけ，Python の OCR (EasyOCR・Tesseract など．
  入っていれば) を**切り出した領域**に当てて照らし合わせてよい．
  OCR は `・` `+` `1` を特に誤るので，**OCR の結果をそのまま採らない**．
- 字種を絞れる OCR なら，被度の欄は `54321+r・` に絞ると良くなる．
  ただし絞りすぎると別の字に化ける (`S・K` → `So`)．
