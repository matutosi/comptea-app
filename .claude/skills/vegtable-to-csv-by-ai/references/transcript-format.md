# 転記表の書き方

画像を読んだ結果は，まず**画像と同じ形の転記表** (TSV) に書く．
縦持ちの CSV への変換 (値の分解・省略された群度の補い・地点ごとの展開) は
`scripts/to_csv.py` が毎回同じ規則で行う．

**転記表に書く理由**: 画像と 1 対 1 で並ぶので，書いたあと画像と見比べて確かめられる．
縦持ちを直に書くと，行・列の取り違えに気づけない．

## 置き場

```
<出力>/transcripts/<表>/      ← 表ごとに 1 つ (名前は Tab12 など)
  meta.tsv  header.tsv  body.tsv  once.tsv  notes.tsv
```

どのファイルも UTF-8・タブ区切り・1 行目が見出し．`#` で始まる行は読み飛ばす (メモに使える)．
無いものはファイルごと作らなくてよい．

## 共通の約束

- **印字のまま書く** (直すのは `scripts/to_csv.py`)．区切りの `・` はそのまま `・` でよい．
- **自信の無い値は末尾に `?`** を付ける (`+・2?`)．status が `check` になる．
- 読めない値は `?` だけを書く (空にすると「非出現」と区別できない)．
- **値ははっきり読めるが目視に回したい行** (下線の意味が決められない，表頭の値の意味が分からない)
  は，任意の `status` 列に `check` と書く (body.tsv・once.tsv・header.tsv)．
  `?` は「読みに自信が無い」の意味なので，こちらには使わない．
- `note` は行ごと．**1 つの地点だけに掛かる注**は `2: 下線` のように地点の番号と `:` を頭に付ける．
  複数の注は `;` で区切る (`1: 下線; 3: 括弧付き`)．
  **1 つの地点だけを check にする**ときは `2: check 小数点の落ちか` のように，番号の後ろを `check` で始める．
- 地点の列の見出しは表頭の**通し番号** (`1` `2` …)．header.tsv と body.tsv で同じにする．
  **通し番号そのものは header.tsv の行に書かない** (列の見出しと重なる)．
- 「無い・測っていない」の `—` `-` は `-` と書く．

## meta.tsv

```
key	value
file	s01114_kinki_010-1
table	Tab.34
title_ja	ハマゴウ―アキグミ群落(1)，ハマゴウ―ハイネズ群集(2)およびハマエンドウ―テリハノイバラ群落(3)
title_raw	Tab. 34. ハマゴウ―アキグミ群落(1)，… Vitex rotundifolia-Elaeagnus umbellata-Gesellschaft(1), …
```

## header.tsv (表頭)

```
item_ja	item_de	unit	1	2	3	note
群落区分	Spalte		1	2	2
調査番号	Feld-Nr.		SS 67	SS 86	SS 79
調査年月日	Datum d. Aufnahme		'83 8 3	'75 10 25	'83 7 2
調査面積	Größe d. Probefläche	m2	2	2	2
草本層の高さ	Höhe d. Krautschicht	m	1.8	0. 5	2
出現種数	Artenzahl		7	7	7
```

- 縦に 2〜3 段に割れた値 (`SS` / `67`，`'83` / `8` / `3`) は**空白でつなぐ**．
  調査番号は `SS-67` に，日付は `1983-08-03` に `scripts/to_csv.py` が直す．
- 日付の年が見出しにあるとき (`Datum d. Aufn. (1983)`) は item_de に年を残す．
- 単位は unit 列に (`m2` `m` `cm` `%` `°`)．
- 小数に空白が入った印字 (`0. 5`) や，小数点が中黒の印字 (`1・8`) は，そのまま書いてよい
  (`scripts/to_csv.py` が `0.5`・`1.8` にする)．
  小数点が見えないとき (`0 5`) は書き足さず，`0 5?` とする．
- **出現種数の行は item_ja を `出現種数`，item_de を `Artenzahl` にそろえる**
  (`scripts/check.py` がこの名前で拾う．印字が「出現 / 種数」と割れていてもつなぐ)．
- 表頭の値に下線があるとき，項目名の括弧の中に下線付きの別名があることがある
  (`Exposition (Waldrand-Exposition)` の `Waldrand` に下線 → 下線の値は林縁の方位)．
  値はそのまま書き，note に `2: 下線 (林縁の方位)` のように意味を書く．
- 意味の分からない印字 (傾斜の欄の `L` など) は印字のまま書き，`status` を `check`，note に理由．
- **文章の形の表頭** (地点が 1 つ) も同じ形にする．地点の列は `1` だけ．
  `方位, 傾斜：S 35°` は `方位 S` と `傾斜 35` の 2 行に分ける．

## body.tsv (本体)

```
kind	group_ja	group_de	s_name	j_name	layer	1	2	3	4	note
group	群落区分種	Trennart d. Gesellschaft
sp			Elaeagnus umbellata	アキグミ		5・4	4・4	・	・
group	群集標徴種および区分種	Kenn- u. Trennarten d. Ass.
sp			Pseudotsuga japonica	トガサワラ	B1	3・3	4・3	4・3	4・4
sp					B2	1・1	・	+	・
sp					K	+・2	1・1	・	・
sp			Sasa borealis	スズタケ	K1;K2	3・3	1・2	5・4	2・2	下線: 3 列目
```

- `kind` は `group` (見出しの行) か `sp` (種の行)．
- 見出しが 2 行にわたるとき (`群集標徴種` / `および区分種`) は 1 行につなぐ．
- **同じ種の階層ごとの行**は，学名・和名を空にして階層と値だけ書く (上の種を引き継ぐ)．
- 値の欄は**地点の数だけ必ず埋める** (非出現も `・` と書く)．
  空欄を残すと「書き漏れ」か「非出現」か分からない．
- **2 段組の表**は，左の段を全部書いてから右の段を続ける (同じ地点の列)．
  右の段の頭に見出しが無ければ，左の段の最後の見出しの続き．何も書かない (直前の見出しを引き継ぐ)．
- 学名と和名が 2 行に割れた種 (学名だけの行の次の行に和名と値) は，1 行にまとめる．
- `S, K̲` のように階層の欄に 2 つあるときは，[table-structure.md の階層](table-structure.md#階層) に従う．
  下線の組み方が一貫していれば**階層ごとの 2 行に分ける** (下線の値を下線の階層の行へ，残りをもう一方へ)．
  確かめられなければ `S;K` と書く (`scripts/to_csv.py` が status を `multi` にする)．
  下線の付いた値は note に `1: 下線` と書く．
- 同じ種が 2 つの見出しの下に重ねて載ることがある (印字どおり 2 行に書く．check.py の重複に出るが正しい)．
- 常在度表のセルは `IV(+-3)` `V` のまま．
- 1 行書くごとに，画像の印字の数と列の数が合うかを確かめる．

## once.tsv (1 回出現の種)

```
plot	s_name	j_name	layer	value	note
1	Artemisia princeps	ヨモギ		1・2
1	Robinia pseudoacacia	ハリエンジュ		+
1	Evodiopanax innovans	タカノツメ	B2	+
1	Lindera obtusiloba	ダンコウバイ	B2	1・2
1	Lindera obtusiloba	ダンコウバイ	S	1・2
1	Lindera obtusiloba	ダンコウバイ	K	+
```

- `in N:` の地点ごとに，種 × 階層を 1 行ずつ．`B2—1・2, S—1・2, K—+` は 3 行．
- ページで割れた種名はつなぐ．続きのページにあふれた分も同じファイルに続け，
  note に `続き: <ページのファイル名>` と書く (出どころを CSV に残すため)．
- **1 地点だけの表には 1 回出現の段落が無い** (全種が本体にある)．once.tsv は作らない．

## notes.tsv (注記と，表頭に無い地点の情報)

注記はもう縦持ちの形で書く (地点への割り当てが文章の読解なので)．

```
plot	item_ja	item_de	value	unit	value_raw	status	note
1	調査地	Lage d. Aufn.	熊野郡久美浜町湊宮		Lfd. Nr. 1, 3: Kumihama-cho, Kumano-gun 熊野郡久美浜町湊宮 (6. Juli 1983)	ok
3	調査地	Lage d. Aufn.	熊野郡久美浜町湊宮		(同上)	ok
1	調査年月日	Datum d. Aufn.	1983-07-06		6. Juli 1983	ok
1	出典	Nachweis	原調査資料		Original 原調査資料	ok
```

- `Lfd. Nr. 1, 3:` のように複数の地点にかかる値は，地点ごとに行を分ける．
- 日付はここでは自分で `YYYY-MM-DD` にする．独語・英語の月名 (`Juli` `Nov.`) に注意．
- **全地点に共通の値** (`Präf. Nara 奈良県`・1 行だけの調査年月日) は `plot` を空にする．
  `scripts/to_csv.py` が表の全地点に展開する．
- 県など地点の情報のうち，項目名の無いものは近い項目名を使う (`調査地 (県)` など)．
